# Project Thumbnails

This directory contains thumbnail images for your portfolio projects.

## Adding Screenshots

To add project thumbnails:

1. Take a screenshot of your project (recommended size: 1200x800px or 16:9 aspect ratio)
2. Save the screenshot as a PNG file in this directory
3. Name the file to match the project (e.g., `weather-app.png`, `snake-game.png`)

## Current Projects

- **weather-app.png** - Screenshot of the Weather Forecast App
- **snake-game.png** - Screenshot of the Snake Game

## Tips

- Use a consistent aspect ratio for all thumbnails (16:9 recommended)
- Capture the most visually appealing part of your project
- Ensure the screenshot is clear and high quality
- PNG format is preferred for better quality
- Optimal resolution: 1200x800px or higher

## Fallback Behavior

If a thumbnail image is not found, the project card will display a gradient background with the project icon as a fallback.
